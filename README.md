# 📡 台股雷達 | TWSE Signal Dashboard

AI 驅動的台股買賣訊號分析平台。

## 功能

- 🔍 **個股 AI 診斷** — 輸入任何台股代號或名稱，AI 即時搜尋最新資料，給出明確的買進／賣出／觀望判定
- 📈 **買進訊號清單** — 六維綜合評分篩出值得關注的股票
- 📉 **賣出訊號清單** — 提醒應獲利了結或減碼的標的
- 📊 **技術指標儀表板** — KD、RSI、MACD、均線、法人籌碼一目了然

## 分析方法

綜合評分整合六大維度：
1. KD 隨機指標（黃金/死亡交叉、超買超賣區）
2. RSI 相對強弱（70 過買 / 30 超賣）
3. MACD 趨勢動能
4. 均線位階（5/20/60 日均線）
5. 三大法人籌碼動向
6. 基本面估值（本益比 + 殖利率）

## 技術

- React + Vite
- Claude AI API (with web search)
- GitHub Pages 自動部署
